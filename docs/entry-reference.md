# Entry 원작 분석 및 WFZ 구현 참고서

이 문서는 `바운스어택의 리메이크.ent`를 분석해, 이후 학생들이 “원작의 ○○처럼 구현해 주세요”라고 요청했을 때 웹 버전 WFZ에 적용할 수 있도록 정리한 개발 기준이다.

## 적용 원칙

- 게임 설정, 캐릭터 구성, 기술 수치, 조작키는 최신 `1학년_김준호_WFZ_개발제안서_수정본.docx`가 최우선 기준이다.
- Entry 원작에서는 캐릭터 구동 구조, 공격 표현 방식, 전투 피드백, 화면 흐름만 참고한다.
- 원작의 이미지·소리·캐릭터 이름·아이템·모드·수치를 그대로 복제하지 않는다.
- Entry 블록을 한 줄씩 옮기지 않고 Phaser의 물리, 상태 머신, 타이머, 트윈으로 같은 플레이 감각을 재구성한다.

## 프로젝트 구조 요약

분석한 `.ent` 파일은 gzip 압축된 Entry 프로젝트이며 `temp/project.json`과 이미지·소리 리소스로 구성된다.

- 장면 7개: 메인, 인게임 설정, 캐릭터 선택, 맵 선택, 인게임, 게임 방법, 썸네일
- 오브젝트 377개
- 변수 988개
- 메시지 104개
- 사용자 함수 12개
- 분석된 블록 노드 약 58,000개(숫자·문자·조건 블록 포함)
- 인게임 장면이 전체 로직의 대부분을 차지하며, 플레이어별 물리·무기·효과 오브젝트가 대칭으로 구성된다.

## 캐릭터 구동 방식

### 1. 표시 오브젝트와 물리 오브젝트 분리

원작은 `1player`/`2player` 표시 오브젝트와 `1P 물리엔진`/`2P 물리엔진`을 분리한다. 무기 역시 `1P 파이터`, `1P 총`, `1P 물뿌리기`처럼 별도 오브젝트가 플레이어 위치와 방향을 따라간다.

웹 버전에서는 `Fighter`가 물리와 표시의 중심이지만 다음 책임은 분리해서 유지한다.

- `Fighter`: 이동, 점프, 공격 상태, 피격 상태, 체력·마나
- `CombatSystem`: Hitbox/Hurtbox 충돌과 동시 타격
- `FightScene`: 무기별 시각 효과, 투사체, 화면 흔들림, 라운드 흐름
- `FightHUD`: 체력·마나·고유 자원과 라운드 표시

### 2. 관성 이동

원작은 키 입력 시 좌우 속도 변수에 약 `0.8`씩 가속을 누적하고, 입력이 없을 때 속도에 약 `0.96`을 곱해 감속한다. 즉시 일정 속도로 바뀌는 방식이 아니다.

웹 버전 적용 기준:

- 지상에서는 빠르게 가속하고 손을 떼면 강하게 감속한다.
- 공중에서는 가속과 감속을 줄여 방향 전환에 관성을 남긴다.
- 캐릭터별 `moveSpeed`는 최고 속도이며 무거운 캐릭터는 가속과 최고 속도가 낮다.
- 방향을 반대로 누르면 즉시 뒤집히지 않고 짧은 제동 구간을 거친다.

### 3. 점프와 중력

원작은 점프 시 중력 변수를 약 `2.5`로 만들고 매 반복마다 약 `0.1`씩 감소시키는 방식으로 포물선을 만든다. 발판 접촉과 “점프 가능” 변수를 따로 관리한다.

웹 버전 적용 기준:

- Arcade Physics 중력을 사용한다.
- 입력 누락을 줄이기 위해 점프 버퍼를 둔다.
- 발판을 벗어난 직후에도 잠깐 점프 가능한 코요테 타임을 둔다.
- 점프키를 짧게 떼면 상승 속도를 줄이는 가변 점프로 낮은 회피와 높은 발판 이동을 모두 지원한다.
- 중력 1650 기준 캐릭터별 점프 속도 700 안팎을 사용해 최고 높이 약 148px 이상을 확보한다.
- 공허 맵 발판은 아래에서 통과하고 위에서 착지하는 단방향 발판으로 구현한다.

### 4. 반동과 상태 이상

원작은 이동 속도와 별도로 반동, 자석 밀치기 X/Y, 바람 밀치기, 기절, 속박, 공포, 둔화, 이동 불가, CC 저항 변수를 둔다. 반동 벡터는 반복 중 약 `0.96` 감쇠되어 자연스럽게 멈춘다.

웹 버전 적용 기준:

- 피격 넉백은 이동 입력과 분리한다.
- 피격 경직 중에는 입력을 잠그고 넉백을 점차 감쇠한다.
- 기절, 둔화, 부활 무적은 종료 시각을 가진 명시적 상태로 관리한다.
- 동시 타격은 한쪽 공격이 먼저 처리됐다는 이유로 사라지지 않게 같은 프레임의 Hitbox를 먼저 저장한다.

## 무기 스크립트 패턴

### 근접 격투 (`1P 파이터`)

- 기본·스킬·필살 입력을 분리한다.
- 공격 중 `move_x`, 크기 변경, 회전으로 전진감과 타격감을 만든다.
- 연속 공격은 메시지와 중첩 타격 변수로 단계별 판정을 낸다.
- 공격 종료 후 딜레이와 상태 변수를 반드시 초기화한다.

WFZ 적용 예: 주먹 캐릭터의 강펀치 전진, 어퍼컷 띄우기, 투지 기반 펀치 러시.

### 총기 (`1P 총`)

- 총알과 탄피를 복제 오브젝트로 생성한다.
- 방향, 탄 퍼짐, 반동, 밀치기 상태를 별도 변수로 계산한다.
- 기본·스킬·필살에 따라 생성 수와 반복 간격이 달라진다.

WFZ 적용 예: 최후의 전쟁변기의 평타는 한 번에 피해 2 탄환 4발을 58ms 간격으로 발사하고, 매 3번째 평타만 6발을 발사한다. 갈고리는 이동·끌어오기·2초 기절, 필살기는 1초 간격 레이저 3발로 분리한다.

### 식물·물뿌리기 (`1P 물뿌리기`)

- 새싹, 나무, 자연 바람 같은 복제 오브젝트를 단계적으로 만든다.
- 설치 위치와 방향을 저장한 뒤 성장·이동 효과를 이어 붙인다.
- 단순 직선 공격뿐 아니라 설치형·지연형 공격을 사용한다.

WFZ 적용 예: 농부는 물 입자 10개, 최대 3개 씨앗, 50회 급수 후 나무 성장, 30초 오라, 나무 추적 폭발을 사용한다.

### 중량·철갑 (`1P 철갑`)

- 공격 중 이동 제한과 기절 상태를 함께 관리한다.
- 에어본, 강한 반동, 화면 진동을 사용한다.
- 불똥 같은 다수의 짧은 효과 오브젝트로 무게감을 강조한다.

WFZ 적용 예: 맨틀속에서 깨어난 존제는 투척 돌의 직접·범위 피해, 순차 바위 기둥 6개, 10초 광폭화와 불 지속 피해를 사용한다.

### 돌진·다단 베기 (`1P 칠흑`)

- X/Y 이동을 여러 단계로 나눠 빠른 돌진 궤적을 만든다.
- 다단 타격, 에어본, 기절, 잔상, 크기 변화를 함께 사용한다.
- 공격 시작·타격·마무리 단계를 별도로 초기화한다.

WFZ 적용 예: 특수 장검의 내려찍기 파편과 화면 연속 베기. 총피해는 수정본 기준 55를 유지한다.

## UI와 전투 피드백

원작에서 참고할 완성도 요소:

- 메인 → 설정 → 캐릭터 → 맵 → 전투로 역할이 분명한 장면 흐름
- 선택 카드의 반복 애니메이션과 선택 상태 표시
- 플레이어별 체력·마나 바와 프로필
- 받은 피해·회복 수치의 떠오르는 텍스트
- 기절·둔화·방어막 등 상태를 별도 효과로 표시
- 공격별 화면 진동 강도 구분
- 승리 메시지와 재시작 동작

WFZ에서는 다음 편의 기능을 추가한다.

- ESC 일시정지: 계속하기, 현재 라운드 재시작, 파이터 선택, 메인 메뉴
- 결과 화면: 재대결, 파이터 선택, 메인 메뉴
- 메뉴 ESC 뒤로가기와 숫자키 빠른 선택
- 같은 파이터 선택 시 2P 대체 색상
- 마나 부족 알림, 피해 숫자, 공격별 색상 효과

## Word 기준으로 유지할 고정 설정

- 웹 기반, 같은 키보드의 로컬 2인 PvP
- 캐릭터 6명: 고대 전사의 귀환, 궁극의 주먹, 최후의 전쟁변기, 시간을 다스리는자, 농부, 맨틀속에서 깨어난 존제
- 맵 2개: 초원 평지, 공허의 다층 발판
- 최대 체력 150, 최대 마나 100, 시작 마나 100, 초당 마나 회복 5
- 1P: A/D 이동, W 점프, E 기본, R 스킬, Q 필살기
- 2P: L/' 이동, P 점프, [ 기본, ] 스킬, O 필살기
- 한 판 또는 3판 2선승
- 동시 사망은 전체 대전 무승부
- 공허 추락 시 피해 15 후 상단 복귀와 짧은 무적
- 온라인, 로그인, 랭킹, 상점, 저장, 스토리, 제한 시간은 구현하지 않음

## 수정본 캐릭터 핵심 규칙

- 고대 전사의 귀환: 평타 7, 내려찍기 20 + 파편 5×3, 연속 베기 총 55.
- 궁극의 주먹: 평타 10, 어퍼컷 20과 0.8배 둔화 3초, 투지 0~4에 따라 필살기 30/40/60과 약 3초 기절.
- 최후의 전쟁변기: 피해 2 탄환 4발, 매 3번째 6발, 갈고리 피해 10과 2초 기절, 레이저 25×3.
- 시간을 다스리는자: 전방위 파동 피해 3과 시간 스택, 5초간 속도 1.5배, 스택에 따라 1~5초 시간 정지와 분침 연사.
- 농부: 물 입자 피해 1×10, 씨앗 최대 3개, 50회 급수 후 30초 나무 오라, 나무당 추적 폭발 피해 30.
- 맨틀속에서 깨어난 존제: 돌 직접 7 + 범위 3, 바위 기둥 20×6, 10초 광폭화 중 용암 평타·강화 기둥·불 지속 피해.

## 이후 프롬프트 해석 예시

- “원작 총처럼” → 투사체 복제, 탄 퍼짐, 반동, 탄피, 점사 간격을 참고한다.
- “원작 물뿌리기처럼” → 설치 위치 저장, 새싹/덩굴 성장, 지연 발동을 참고한다.
- “원작 철갑처럼” → 긴 준비 동작, 공격 중 이동 제한, 강한 넉백, 파편을 참고한다.
- “원작 칠흑처럼” → 단계별 돌진, 다단 타격, 잔상, 마무리 넉백을 참고한다.
- “원작 움직임처럼” → 가속 누적, `0.96` 계열 감쇠, 별도 반동 벡터, CC 잠금을 참고한다.
- “원작 UI처럼” → 화면의 구체적인 설정값은 복제하지 않고 선택 상태, HUD 가독성, 버튼 피드백만 참고한다.

이 문서를 수정할 때는 실제 구현 파일도 함께 갱신한다. 전투 수치는 `src/game/data/fighters.ts`, 이동·상태는 `src/game/entities/Fighter.ts`, 충돌은 `src/game/systems/CombatSystem.ts`, 화면 흐름은 `src/game/scenes`에 있다.
