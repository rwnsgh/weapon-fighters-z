# WFZ: Weapon Fighters Z

한 대의 컴퓨터와 하나의 키보드로 두 명이 대전하는 2D 사이드뷰 플랫폼 액션 게임 MVP입니다. React 없이 Vite, TypeScript, Phaser 3로 제작했습니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev
```

화면에 표시되는 로컬 주소를 데스크톱 브라우저에서 여세요.

```bash
npm run build
npm run test
npm run lint
```

## 조작

| 플레이어 | 이동 | 점프 | 기본 공격 | 스킬 | 필살기 |
|---|---|---|---|---|---|
| 1P | A / D | W | E | R | Q |
| 2P | L / ' | P | [ | ] | O |

ESC를 누르면 전투가 완전히 멈추고 계속하기, 현재 라운드 다시 시작, 파이터 선택, 메인 메뉴를 고를 수 있습니다. F2를 누르면 Hurtbox, 활성 Hitbox, 상태, 체력, 마나, 투지, 공격 단계와 속도 벡터를 확인할 수 있습니다.

모든 파이터는 체력 150, 마나 100으로 시작하며 마나는 초당 5 회복됩니다. 점프키를 짧게 누르면 낮게, 길게 누르면 높은 발판까지 점프합니다.

## 게임 흐름

타이틀 → 승부 방식 → 파이터 선택 → 전장 선택 → 대전 → 결과 순서로 진행합니다. 한 판 승부와 3판 2선승을 지원하며, 양쪽이 같은 판정 주기에 KO되면 무승부입니다.

## 파이터

- **고대 전사의 귀환**: 내려찍기와 칼날 파편 3개, 총 피해 55의 화면 연속 베기
- **궁극의 주먹**: 3초 둔화 어퍼컷과 투지에 따라 피해가 30/40/60으로 증가하는 펀치 러시
- **최후의 전쟁변기**: 4발 점사(매 3번째 6발), 갈고리 이동·끌어오기, 레이저 3줄기
- **시간을 다스리는자**: 시간 스택, 5초 가속, 1~5초 시간 정지와 분침 연사
- **농부**: 물 입자로 최대 3개 씨앗을 나무로 키우고 오라와 추적 폭발 사용
- **맨틀속에서 깨어난 존제**: 돌 투척, 바위 기둥 6개, 10초 광폭화와 불 지속 피해

두 플레이어는 같은 파이터를 선택할 수 있으며 이때 2P는 대체 색상으로 표시됩니다.

## 전장

- **초원 평지**: 낙사 없는 넓은 기본 전장
- **공허의 다층 발판**: 좌우 대칭의 6개 발판을 오가며 싸우고, 추락 시 체력 15를 잃은 뒤 상단에서 1초 무적으로 재등장. 모든 파이터가 아래 발판에서 최상단까지 이어서 올라갈 수 있습니다.

## 대전 밸런스

- 같은 파이터를 고르면 1P와 2P는 색상만 다르고 체력, 이동, 공격 판정과 피해가 완전히 같습니다.
- 같은 프레임에 양쪽 공격이 닿으면 플레이어 번호와 관계없이 동시 타격으로 처리합니다.
- 미니건은 긴 사거리 대신 피해와 경직이 낮고 빈틈이 큽니다. 바위는 가장 느리지만 근거리 보상이 높으며, 나머지 파이터는 속도·범위·고유 효과로 역할을 나눕니다.
- 점프와 공격 입력에는 짧은 입력 버퍼가 있어 착지 직전이나 공격 회복이 끝나기 직전의 입력도 자연스럽게 이어집니다.

## 구조

전투 수치는 `src/game/data/fighters.ts`에 모여 있습니다. `Fighter`가 상태 머신과 공격 단계를 관리하고, `CombatSystem`이 Hitbox/Hurtbox 교차를 판정합니다. Phaser와 독립적인 전투 계산은 `CombatLogic.ts`, 라운드 판정은 `RoundManager.ts`에 있어 자동 테스트할 수 있습니다.

향후 캐릭터는 `FighterConfig` 데이터와 캐릭터별 고유 효과를 추가하는 방식으로 확장할 수 있습니다.
